# Interstellar Lite Pro - AI Web Development Platform

🚀 **Production-ready AI Web Development Platform** with GitHub Pages publishing, website cloning, professional modals, dark/light themes, and mobile optimization.

## ✨ Features

- **🤖 AI-Powered Website Generation** - Create stunning websites with natural language prompts
- **📱 Fully Mobile Optimized** - Perfect responsive design for all devices
- **🎨 Professional UI** - Custom modals, SVG icons, glassmorphism effects
- **🌓 Dark/Light Themes** - Complete theme system with smooth transitions
- **🚀 GitHub Pages Publishing** - One-click deployment to GitHub Pages
- **🌐 Website Cloning** - Clone and enhance any website with modern design
- **📁 GitHub Import** - Import existing projects from GitHub repositories
- **💾 Auto-Save** - Automatic project saving every 2 seconds
- **⌨️ Keyboard Shortcuts** - Power user features (Ctrl+S, Ctrl+Enter, F11, Escape)
- **🎯 Monaco Editor** - Professional code editing with syntax highlighting

## 🔧 Vercel Deployment

This project is optimized for Vercel deployment with:

- **Static Site Configuration** - Uses `public/` directory for static files
- **Custom Headers** - Security headers and CORS configuration
- **Build Optimization** - No build step required for static HTML
- **CDN Integration** - Monaco Editor and fonts served from CDN

### Deployment Steps:

1. **Fork/Clone** this repository
2. **Connect to Vercel** - Import your repository in Vercel dashboard
3. **Deploy** - Vercel will automatically detect the configuration
4. **Access** - Your app will be live at `https://your-project.vercel.app`

### Environment Variables (Optional):

- `OPENROUTER_API_KEY` - For AI functionality (already included)
- `TAVILY_API_KEY` - For web search and cloning (already included)
